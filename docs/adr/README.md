# Décisions d'architecture

Ce dossier garde une trace des décisions structurantes du projet, celles qui coûtent cher à
revenir en arrière une fois le code écrit autour. Une page par décision, numérotée dans l'ordre
où elle a été prise.

Chaque page suit le même plan : le contexte qui a rendu la décision nécessaire, la décision
elle-même en une ou deux phrases, puis ses conséquences, y compris celles qu'on accepte comme
inconfortables. Une ADR n'est pas réécrite quand le contexte change : si la décision est
révisée, une nouvelle page la remplace et renvoie vers l'ancienne.

Tout ne mérite pas une ADR. Le choix d'un nom de méthode ou l'organisation d'un dossier se
discute dans la revue de code ; ce dossier est réservé à ce qui engage plusieurs PR à venir.
